# HisaBoo – Personal Expense Tracker

A mobile personal expense tracker built with **Flutter and Dart**. The app uses a cream, ivory and pastel-green interface and stores expense records locally on the device.

## Features
- Welcome/profile setup
- Expense dashboard with current-month and all-time totals
- Spending breakdown by category
- Add, edit and delete expenses
- Search expenses and filter by category
- Transaction date and payment method
- Local persistence using SharedPreferences
- Responsive Android-friendly layout

## Technology
- Flutter
- Dart
- SharedPreferences (local key-value storage)
- intl (date and currency formatting)

## Requirements
- Flutter SDK (stable)
- Android Studio or Android SDK
- Android phone and USB cable, or an Android emulator

## Run the project
1. Extract the complete project folder.
2. Open a terminal inside the `HisaBoo_Flutter` folder.
3. Run:

```bash
flutter doctor
flutter pub get
flutter run
```

## Generate APK
Connect an Android phone with USB debugging enabled, or configure an emulator.

```bash
flutter build apk --release
```

The release APK is generated at:

`build/app/outputs/flutter-apk/app-release.apk`

To install it using ADB:

```bash
adb install -r build/app/outputs/flutter-apk/app-release.apk
```

You can also copy the APK to your phone and open it to install it. If Android asks, allow installation from that file manager for this APK only.

## Data and privacy note
This learning project stores the profile name, email and expense records locally using SharedPreferences. It does not connect to a server or provide secure multi-user authentication. Do not enter sensitive financial or account information. Clearing app data or uninstalling the app may remove locally stored records.

## Practical demonstration checklist
- Launch the app and complete the profile setup.
- Add an expense with amount, category, date and payment method.
- Show the dashboard totals and category breakdown.
- Search and filter the transaction list.
- Edit an expense and demonstrate deleting one.
- Close and reopen the app to show that saved records persist.
- Bring the installed app, generated APK and full source folder.
